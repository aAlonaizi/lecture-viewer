# دفتر المحاضرة

تجربة عرض وكتابة على شرائح الفصل الثالث: تحليل الخوارزميات.

https://aalonaizi.github.io/lecture-viewer/

الحفظ التلقائي محلي. زر «مزامنة» يحفظ الملاحظات والشعب في مستودع خاص منفصل بعد ربط حساب المدرس برمز محدود الصلاحية. لا تُرفع إلى هذا المستودع العام. يتوفر تصدير HTML مستقل للطلبة ونسخ JSON احتياطية والطباعة إلى PDF.

يمكن أرشفة الشعب واستعادتها. المزامنة لا تنشر الإجابات للطلبة. الروابط المحمية للطلبة غير متاحة بعد، ولا يمكن سحب نسخة سبق تنزيلها.
