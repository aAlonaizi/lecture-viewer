# دفتر المحاضرة

https://aalonaizi.github.io/lecture-viewer/

اختر الشعبة واضغط «نشر الملاحظات». زر «رابط الشعبة» ينسخ رابطًا يفتحه الطالب دون دخول؛ تحديث الصفحة يعرض آخر شرح منشور. الدخول الخاص بالمدرس يُربط مرة واحدة في المتصفح.

الشرائح والواجهة مستضافة على GitHub Pages. نشر الملاحظات وحماية الكتابة والأرشيف تعمل عبر خدمة مستقلة في Cloudflare. لا توجد مفاتيح المدرس أو بيانات الأرشيف في هذا المستودع.

أرشفة الشعبة توقف رابط شرحها. استعادتها ونشرها مجددًا يصدر رابطًا جديدًا. لا يمكن سحب نسخة صُوّرت أو نُزّلت سابقًا.
